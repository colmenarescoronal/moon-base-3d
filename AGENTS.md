# Instrucciones del proyecto para futuras tareas

El usuario quiere seguir desarrollando Moon Base y pidió que **cada petición quede documentada**.

Al completar cualquier petición que cambie este proyecto:

1. Actualiza `CHANGELOG.md` con una entrada breve bajo `Sin publicar`: qué cambió y por qué.
2. Actualiza la documentación afectada (`README.md` o `docs/`) cuando cambien controles, arquitectura, contenido, instalación o procedimientos de desarrollo.
3. Si la petición no cambia código, documenta igualmente el resultado o la decisión en el archivo pertinente y registra la tarea en `CHANGELOG.md`.
4. Mantén clara la diferencia entre lo que el proyecto ya implementa y las propuestas futuras.
5. En la respuesta final, menciona la documentación actualizada y las comprobaciones realizadas.

Esta instrucción no exige crear documentación extensa para cambios pequeños: una entrada concreta y los ajustes pertinentes son suficientes.
